# Voiceover

The narration of the 58-second film, as placed in the mix (`scripts/audio/score.py`).
Generated with Kokoro-82M, voice `am_michael`, speed 0.9, one line at a
time (`scripts/audio/vo.py`); the files are in `public/audio/vo/`. The brand is
spoken as "Do or Die" and the exam as "U.P.S.C."; captions use the written forms.

To record a human voice instead, read each line to the same length (± 0.2 s),
save it as `public/audio/vo/<id>.wav` (48 kHz) and re-run `score.py`: nothing in
the picture needs to move.
